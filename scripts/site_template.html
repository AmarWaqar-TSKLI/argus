How it works

    
A LangGraph state machine. Cheap, deterministic checks run first; the vision model is only used for what code cannot see.

    

      
Explore
Playwright crawls the site page by page, logging in first when asked.

      
Check
DOM checks for broken links, failed requests, JS errors and accessibility. SSIM diffs catch visual drift.

      
Use it
Fills and submits every form and clicks every button, then judges what happened.

      
Verify & report
A skeptic agent re-checks every visual claim, then the report and GitHub issues are written.

    

  


  

    
Problems I hit, and how I solved them

    

      
The model invented bugs

        
ProblemThe vision model reported an "unreadable nav" on a page with nothing wrong.

        
FixA second, skeptical agent re-examines every visual claim and is biased toward rejecting it. Rejected claims stay in the report for transparency.

      
Free tiers kept stalling

        
ProblemFree-tier rate limits froze audits for minutes at a time.

        
FixFast failover across providers (Gemini, then Groq) instead of waiting, plus perceptual-hash dedup so no screen is judged twice. Cost stays at $0.

      
Long runs died midway

        
ProblemA crash halfway through a big site meant starting over.

        
FixEvery graph step checkpoints to SQLite. --resume continues from the exact page the run died on.
